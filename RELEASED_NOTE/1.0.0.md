# Release Notes - v1.0.0

**Release Date:** 2026-10-06  
**Version:** 1.0.0  
**Bump Type:** major

## Summary
Initial major release of `stream-overlay-socket`, introducing a unified command-line interface (CLI), automated Git dependency synchronization for overlays via `meta.yaml`, a decoupled server architecture, and cross-platform executable builds.

## What's Changed

### Added
- **Command-Line Interface (CLI)**: Centralized command router in `src/modules/cli/index.ts` with subcommands:
  - `serve`: Launches the web & WebSocket server with configurable options (`-p/--port`, `-h/--host`, `--sync-libs`).
  - `overlay list`: Scans and lists installed overlays in `static/` with metadata and library dependencies.
  - `overlay sync [name]`: Synchronizes libraries declared in `meta.yaml` across overlays.
  - `overlay install <repo>`: Clones/updates an overlay from Git and automatically pulls its dependencies.
  - `update check`, `update download`, and `update version`: Manages socket core releases from GitHub.
- **Overlay Git Library Manager (`src/modules/overlay/libs.ts`)**:
  - Reads and normalizes `meta.yaml` / `meta.yml` dependency declarations.
  - Resolves shorthand (`owner/repo`), HTTPS, and SSH URLs.
  - Automatically clones missing libraries into `static/libs/` and updates existing ones via `git pull` using Bun shell (`Bun.$`).
- **Interfaces (`src/modules/interfaces/overlay.interface.ts`)**: Added types for `OverlayMeta`, `LibRepoInfo`, `SyncLibResult`, and `SyncOverlayResult`.
- **Scripts in `package.json`**: Added `serve`, `cli`, `overlay:sync`, `overlay:list`, and `rules:sync` (`bunx dethz-crawler sync`).

### Changed
- **Decoupled Server Architecture (`src/server.ts`)**: Separated server bootstrap into `startServer()`, resolving circular dependencies between route declarations and WebSocket topic publishers.
- **Application Entry Point (`src/index.ts`)**: Dispatches CLI arguments automatically, defaulting to starting the server when invoked with no arguments (preserving backward compatibility with `bun run dev`).
- **Static Page Routes (`src/routes/staticPage.ts`)**: Extended `metadataInterface` to support `libs?: string[]`.
- **Spotify WebSocket Publisher (`src/routes/ws/modules/spotify/index.ts`)**: Safely publishes to topics using optional chaining with `ws.publish` fallback.
- **Documentation (`README.md`)**: Updated setup, scripts table, CLI usage, `meta.yaml` specifications, and rule synchronization with `dethz-crawler`.

### Fixed
- Fixed circular dependency error (`ReferenceError: Cannot access 'routes' before initialization`) preventing tests from running against `src/routes`.

### Removed
None
